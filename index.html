Proyectos destacados

Pagina Web Fundacion Patitas Felices

Desarrollo de una maqueta web estática para una fundacion, enfocada en dar a conocer su labor de rescate y adopción de animales. El sitio incluye inicio con banner y carrusel, secciones de misión y visión, testimonios, módulo de impacto con estadísticas, catálogo de animales con tarjetas, perfiles detallados, galería y formulario de contacto.
Fue construido con HTML y CSS puro, aplicando una experiencia de usuario clara y atractiva alineada con la identidad de la fundación.

Gestion De Produccion ACME

Desarrollo de una aplicación web para la automatización del proceso productivo de una planta, permitiendo la gestión integral de usuarios, inventario y producción. El sistema incluye autenticación segura, control de materia prima, creación de productos con fórmulas y ejecución de procesos productivos que actualizan automáticamente el stock. Además, incorpora visualización de inventarios con filtros de búsqueda y reportes de producción detallados.
