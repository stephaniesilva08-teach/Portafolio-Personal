Proyectos destacados

DeliveryBot – Gestión de Pedidos Internos de cafeteria

*DeliveryBot* es una solución en *n8n* que convierte **Telegram** en una terminal inteligente para pedir en cafeterías institucionales y monitorear compras en tiempo real. Centraliza menú, stock y reportes en **Google Sheets**, reduciendo esperas un 40%. Además, valida la hora actual (`$now`) para bloquear compras fuera del horario operativo (Lunes a Viernes, 8:00 AM a 5:00 PM), permitiendo solo la consulta del menú.

N8N • GOOGLE SHEETS • TELEGRAM

Pagina Web Fundacion Patitas Felices

Desarrollo de una maqueta web estática para una fundacion, enfocada en dar a conocer su labor de rescate y adopción de animales. El sitio incluye inicio con banner y carrusel, secciones de misión y visión, testimonios, módulo de impacto con estadísticas, catálogo de animales con tarjetas, perfiles detallados, galería y formulario de contacto.
Fue construido con HTML y CSS puro, aplicando una experiencia de usuario clara y atractiva alineada con la identidad de la fundación.

Gestión de inventario (ACME)

Desarrollo de una aplicación de consola en Python para la gestión y trazabilidad de inventarios en múltiples bodegas (Norte, Centro, Oriente), utilizando archivos JSON para la persistencia de datos. El sistema automatiza el registro de productos, el control de entradas y salidas con validación de existencias y la generación de sellos de fecha y hora para cada transacción. Además, incluye módulos de búsqueda por código, historial detallado de movimientos, generación de reportes globales o por zona con opción de exportación a archivo, e interfaz basada en menús con un manejo robusto de excepciones.
